Authority probe

The guest is allowed to request paddle movement. The host computes paddle speed, ball physics, collisions, and score. A modified guest therefore must not be able to publish a score directly.

Connect two peers to run the probe.

This blocks impossible state messages and paddle teleporting. It cannot reliably distinguish a human from a bot that sends only legal paddle inputs, and a malicious host can still cheat because this demo intentionally trusts the host as gameplay authority.

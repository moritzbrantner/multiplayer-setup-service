Multiplayer setup demos

Run the local demo server, then open the same game in multiple tabs or devices.

Tic-Tac-Toe

Two-player reliable, ordered WebRTC DataChannel. Each peer validates moves locally.

Pong

Two-player realtime unordered/unreliable snapshots and paddle input, plus a reliable score/reset channel.

Input-only arena

2–16 participants using either a full WebRTC mesh or host-spoke topology. Only compact input commands are exchanged; every browser applies the same state transition locally.

Two-player sessions can release signaling after setup. Multi-party lobbies keep signaling available so late participants can establish new peer links during the lobby lifetime.
